# 🟢 What is MCP?

* <mark style="color:red;background-color:purple;">**Open-source standard for connecting AI applications to external systems.**</mark>
* <mark style="color:purple;background-color:purple;">MCP is not about giving more intelligence,</mark> <mark style="color:red;background-color:purple;">**it is about giving it an ability to see more**</mark>
* <mark style="color:purple;background-color:purple;">Using MCP, AI applications can connect to data sources, tools and workflows - enabling them to access key information and perform tasks.</mark>
* <mark style="color:red;background-color:purple;">**Developers: MCP reduces development time and complexity when building, or integrating with, an AI application or agent.**</mark>
* <mark style="color:red;background-color:purple;">**AI applications or agents: MCP gives them access to an ecosystem of data sources, tools and apps, which enhances their capabilities and improves the end-user experience.**</mark>
* <mark style="color:red;background-color:purple;">**End-users: MCP results in more capable AI applications or agents that can access user data and take actions on the user’s behalf when necessary.**</mark>

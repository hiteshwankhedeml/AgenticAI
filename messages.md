# Messages

* **Consists of:**
  * Role ⇒ Human, System, AI, Tool
  * Content
  * Metadata ⇒ IDs, token usage
* There can be different types of contents like image, code block etc
* Can be passed as text prompt, as message object (SystemMessage, AIMessages, HumanMessage)&#x20;
* We can pass a list of message objects or dictionary of role and message to the model
* Multimodal can be passed in message as message in content block with type and text/url/base64
